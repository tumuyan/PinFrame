# 界面概述

本节只概述各主菜单和面板包含哪些**选项组**，便于你快速定位功能所在位置；具体每个选项的用法见对应文档。

## 主菜单

- **文件 (File)**：工程的新建 / 打开 / 保存 / 另存为；关闭与重新加载工程；最近工程列表；复制素材到工程目录；**素材管理器**；**删除工程目录未使用的素材**；打开工程所在目录；重载图片；全局设置；导出 PNG 序列 / 导出精灵表；退出。
- **图像 (Image)**：导入图片；从精灵表切片导入；导入 GIF（拆分为帧）；**图像格式设置**（自定义可识别的图片后缀）；**用默认编辑器打开**（在外部图像编辑器中处理当前选中的帧）；**用其他编辑器打开**（子菜单，列出所有已配置的编辑器）；**外部图像编辑器设置**（管理全局的外部编辑器列表）。
- **编辑 (Edit)**：撤销 / 重做；复制 / 粘贴帧属性；复制帧 / 批量复制；删除帧；反转帧顺序；重复延迟（子菜单，设定自动重复间隔）；历史记录（子菜单，可回溯操作）。
- **布局 (Layout)**：切换窗口排布 —— 标准、侧边、四种堆叠组合、自定义分割布局。
- **播放 (Playback)**：开始 / 暂停播放；倒序播放。
- **画布 (Canvas)**：视图缩放（放大 / 缩小 / 适应窗口 / 重置）；滚轮模式（子菜单：缩放视图 或 缩放图片）；背景（子菜单：背景色 / 棋盘格等）；画布设置。
- **视图 (View)**：洋葱皮开关及其设置；参考帧（设为参考 / 设置 / 清除）；主题（子菜单：深色 / 浅色）；语言（子菜单：中文 / 英文）；时间轴视图（子菜单：列表 / 网格 / 网格设置）。
- **关于 (About)**：项目仓库、版本号、构建日期；调试控制。

## 主面板

- **画布 (Canvas)**：核心预览区。支持视图平移与缩放、洋葱皮叠加、参考帧叠加、多帧多选拖拽、锚点手柄拖拽、裁切编辑、栅格化网格显示。
- **时间轴 (Timeline)**：位于底部，提供列表视图与缩略图网格视图两种模式。用于帧的增删改、拖拽重排、多选与批量操作入口。
- **属性面板 (Property)**：位于侧边，针对选中帧提供变换控制：缩放、位置、旋转、镜像、锚点模式、重复移动、相对移动等。

## 弹出式对话框（按需打开）

以下为模态窗口，需要时从菜单或面板调用，不常驻界面：

- 切片对话框（精灵表切片）
- 洋葱皮设置、参考帧设置、栅格设置、画布边框设置
- 复制素材到工程目录、素材管理器、删除工程目录未使用的素材、导出对话框、组装对话框
- 颜色选择器、批量复制对话框、调试设置

> 提示：布局菜单可让你把面板在"画布 + 时间轴 + 属性"之间重新排列，适应不同屏幕与操作习惯。

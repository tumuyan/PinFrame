# 锚点系统（重点）

每一帧的变换（缩放、旋转）都围绕一个**轴心点（Anchor）**进行。在属性面板中可切换四种锚点模式：

| 模式 | 轴心位置 | 行为特点 |
|------|----------|----------|
| **画布中心 (Canvas)** | 画布原点 | 图片始终绕画布中心旋转 / 缩放，会靠近或远离中心。 |
| **图片中心 (Image)** | 图片自身中心 | 图片绕自身中心变换，位置保持不变。 |
| **自定义·画布 (Custom Canvas)** | 画布坐标下的固定点 | 绕画布上指定固定点变换；轴心不随图片移动。 |
| **自定义·图片 (Custom Image)** | 同上，但锚点附着在图片上 | 绕一个"贴"在图片上的相对点变换；图片平移时轴心跟随移动。 |

## 选择建议

- 想让图片原地自转 / 缩放 → **Image**
- 想让图片绕画布中心公转 → **Canvas**
- 想绕画布上一个固定参考点变换（参考点不随图片动） → **Custom Canvas**
- 想绕一个"贴"在图片上的固定相对点变换（图片移动时轴心跟着动） → **Custom Image**

## 使用要点

- 前两种（画布中心 / 图片中心）为"固定语义"轴心：无需手动输入坐标，输入框被禁用。
- 后两种（自定义·画布 / 自定义·图片）为"手动锚点"：启用 X/Y 输入框，并可在画布上拖拽锚点手柄实时调整。
- 仅 **自定义·图片** 会在图片移动时让轴心跟着走；**自定义·画布** 的轴心始终留在画布原地。

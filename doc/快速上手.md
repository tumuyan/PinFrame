# 快速上手

5 分钟跑通"导入 → 调整 → 预览 → 导出"的完整流程。

## 步骤 1：新建并导入

1. 启动 PinFrame（首次打开为空工程，默认画布尺寸与帧率）。
2. 将一组序列帧图片**拖入时间轴**，或菜单 **图像 → 导入 GIF** 拆分动画。
3. 若素材是整张精灵表，用 **图像 → 精灵表切片导入** 按行列切成多帧（见 [导入素材](导入.md)）。

## 步骤 2：调整关键帧

1. 在时间轴中**选中一帧**，右侧属性面板出现该帧的变换选项。
2. 想让图片原地放大 / 旋转：把**锚点模式**设为「图片中心」，再调缩放或旋转。
3. 想让图片绕画布中心转：锚点设为「画布中心」。
4. 需要精细裁掉边角：进入**裁切编辑**（画布上拖 8 个手柄）。
5. 多帧之间要平滑过渡：多选首尾帧，用 **编辑 → 平滑参数**生成补间（见 [调整帧](调整帧.md)）。

## 步骤 3：预览与播放

1. 点 **播放 (Playback)** 菜单的开始按钮，或底部时间轴播放控件预览动画。
2. 开启**洋葱皮**（视图菜单）可半透明叠加前后帧，检查连贯性。
3. 用**滚轮**在画布上缩放视图或缩放图片（由画布菜单的滚轮模式决定）。

## 步骤 4：导出

1. 菜单 **文件 → 导出** 选择 PNG 序列 / 精灵表 / GIF。
2. 设定帧范围（如 `1,3,5-7,10-`）与背景色，确认导出。

# 工程与素材

PinFrame 的工程是一个 JSON 文档，只记录信息、引用外部图片文件，不会把图片复制进工程。

## 保存与加载

- 菜单 **文件 → 保存 / 另存为** 将当前状态写入 `.json` 工程文件。
- 保存时，所有图片路径会**自动转为相对路径**（相对于工程文件所在目录），因此整个工程文件夹移动后仍能正确找到图片。
- **文件 → 打开** 载入已有工程；**最近工程** 列表可快速回到近期文件。

## 复制素材到工程目录

- 当图片分散在电脑各处、需要把工程打包带走时，用 **文件 → 复制素材到工程目录**。
- 该操作会把被引用的外部图片复制到工程文件夹内，并把路径更新为相对路径，确保移动工程不丢失素材。
- 也可通过 **复制素材对话框** 预览将要复制的文件后再执行。

## 素材管理器

**文件 → 素材管理器** 以列表方式总览当前工程引用的所有源图素材，方便排查与清理：

- 每个素材显示：文件名、路径、**使用次数**（被多少帧引用）、有效帧数、禁用帧数、创建时间、修改时间。
- 默认按文件名排序，也可点击表头按任意列排序。
- **素材丢失检测**：文件缺失的素材会在列表中红色加粗标出，预览区与顶部提示栏也会给出提示，便于排查加载后找不到图片的问题。
- 选中一个素材可在预览区查看缩略图，下方列出引用它的帧号。
- **替换素材**：选中素材后，点击预览区下方的**替换素材**按钮（或右键预览图），可选择一张新图片替代当前素材——工程中所有引用该素材的帧都会改指向新文件（原文件仍保留在磁盘，可撤销）。
- 列表中的文件名 / 路径过长时，鼠标悬停会悬浮显示完整内容。
- 勾选多个素材后点击**删除**，可将这些素材从工程中**移除引用**（对应帧一并删除，可撤销）——只移除引用、**不会删除磁盘上的源图文件**。
- 底部提供**全选 / 选中未启用 / 全不选 / 反选** 批量勾选按钮：其中**选中未启用**会选中仅被禁用帧引用（未被任何有效帧使用）的素材。

## 删除工程目录中未使用的素材

**文件 → 删除工程目录未使用的素材** 用于清理工程文件夹里的无用图片：

- 扫描工程目录（含子目录），找出**未被工程引用**且**不是导出结果文件**（如上次导出的 PNG / GIF）的图片。
- 列表仅显示**文件名**（文件已在工程目录下，完整路径可通过悬停查看），并附带**创建时间 / 修改时间**栏位；选中一行可在右侧预览该图片。
- 列表默认全部勾选，也可用**全选 / 全不选 / 反选**调整勾选，确认后删除勾选的图片文件。
- 请注意：该操作会**真正删除磁盘文件**，删除前请仔细核对勾选项。

## 图像格式设置

**图像 → 图像格式设置** 用于自定义可被识别为图片的后缀名：

- 默认支持 `.png` / `.jpg` / `.jpeg` / `.bmp` / `.gif`。
- 可新增 / 删除后缀，统一作用于文件导入过滤与合法性判断，设置会持久保存。

## 重新加载图片

- 若外部图片被替换或编辑过，**文件 → 重载图片** 可让工程重新读取最新版本，无需重新导入。

## 工程设置

- 全局设置（帧率、画布尺寸、背景色、默认导出项等）在 **文件 → 设置** 中调整，会影响后续预览与导出。

## 便携性要点

- 工程文件体积小、纯文本，适合纳入版本管理。
- 移动工程时，连同其引用的图片文件夹一起移动即可；使用「复制素材到工程目录」是最稳妥的打包方式。

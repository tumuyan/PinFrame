# PinFrame 使用说明

> PinFrame（定帧）是一款桌面工具，用于预览、微调与整合序列帧 / 精灵表，同时也是一款通用的 GIF 处理工具。
> 工程以 JSON 存储信息，引用外部图片文件（无损、不复制资源）。

## 常见问题

- **导入图片尺寸不合适会损失精度吗？** 不会。工程仅记录信息并引用原图，导出时按原图重新合成，无损。
- **导出的结果和预览看起来不一样？** 请保存工程后重新导出；若仍不一致，可在「关于 → 调试控制」中开启日志并反馈。
- **工程移动后图片找不到了？** 用「文件 → 复制素材到工程目录」把图片收进工程文件夹，或确保图片与工程文件相对位置不变（路径保存为相对路径）。
- **素材分散在多台电脑？** 同上，复制素材到工程目录是最稳妥的打包方式，之后整个文件夹即可带走。
- **工程里出现找不到的图片？** 用 **文件 → 素材管理器**，缺失素材会红色标出，可快速定位丢失的源图。
- **工程目录里堆了很多没用到的图片？** 用 **文件 → 删除工程目录未使用的素材** 扫描并清理未被工程引用的图片。
- **想导入某种自定义格式的图片？** 用 **图像 → 图像格式设置** 添加对应的后缀名即可。

# 导入素材

PinFrame 提供三种导入方式，覆盖单图、精灵表与 GIF 动画。

## 1. 拖入导入（多张图片）

直接将图片文件拖到**时间轴**区域即可，可一次拖入多张，按顺序成为连续帧。导入后每张图对应一个 `FrameData`，默认以图片中心为锚点、无缩放。

## 2. 从精灵表切片（Slice）

当素材是一张大图、内含按行列排列的多个小图时使用：

1. 菜单 **图像 → 精灵表切片导入**。
2. 在切片对话框中设置行数 / 列数，预览网格是否正确覆盖每个小图。
3. 确认后，自动生成多张帧 —— 它们**共享同一张源图**，但各自带不同的裁切区域（`crop_rect`），因此不会复制图片文件。

适合：游戏素材、统一打包的帧图。

## 3. 导入 GIF

菜单 **图像 → 导入 GIF**，将 GIF 逐帧拆分为工程帧序列。导入后可在时间轴中像普通帧一样调整、预览与导出。

## 导入后的常见操作

- 在**属性面板**中调整某帧的缩放、位置、旋转、锚点（见 `锚点系统`）。
- 在**时间轴**中拖拽重排、多选批量调整、复制 / 删除帧。
- 需要无损保留素材时，可用 **文件 → 复制素材到工程目录** 把外部图片收进工程文件夹，保证工程移动时不丢失文件。

> 工程只记录图片的引用路径（保存时转为相对路径），原图始终无损，不会被重复复制或压缩。

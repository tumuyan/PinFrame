# 调整帧

选中时间轴中的一帧（或多帧）后，可在属性面板和画布上对该帧做精细调整。

## 属性面板变换

- **缩放**：整体缩放，或分别设置 X / Y 倍率。X/Y 不同倍率会产生拉伸或压缩；倍率为负即镜像翻转。
- **位置**：沿 X / Y 平移图片。
- **旋转**：设置角度；可用「相对旋转」在现有角度上追加，而不是覆盖。
- **锚点模式**：决定缩放 / 旋转的轴心，详见 [使用说明 #锚点系统](使用说明.md#锚点系统重点)。
- **重复移动定时器**：让帧按设定间隔自动重复移动，便于制作循环位移。
- **相对移动**：以当前值为基准偏移，而非直接设定绝对值。

## 裁切编辑

- 在画布上进入裁切模式，图片四周出现 **8 个手柄**（四角 + 四边）。
- 拖动手柄即可裁掉不需要的区域；裁切范围记为该帧的 `crop_rect`。
- 精灵表切出的多帧共享同一源图、各自带不同裁切，正是用此机制实现。

## 平滑参数（补间）

用于在多帧之间自动生成平滑过渡，省去手动逐帧调整：

1. 在时间轴中**选中至少两帧**（首尾之间会被补间）。
2. 菜单 **编辑 → 平滑参数**，弹出对话框：
   - **模式**：线性 / 平均 / 缓入 / 缓出 / 缓入缓出。
   - **参数**：勾选要补间的项 —— 缩放、位置 X、位置 Y、旋转。
   - **旋转路径**（仅勾选旋转且非「平均」时可用）：自动 / 最短 / 顺时针 / 逆时针，决定角度如何绕行。
3. 确认后，首尾之间的帧会被自动填充中间值。

## 多选与批量

- 在时间轴中框选或多选多帧后，属性面板的调整会**批量作用于所有选中帧**。
- 多选后也可在时间轴上整体拖拽、复制、删除。

## 复制 / 粘贴帧属性

- **编辑 → 复制帧属性** 记下当前帧的变换参数，**粘贴帧属性** 应用到另一帧，便于保持多帧风格统一。

# 预览与播放

PinFrame 的交互预览由画布与时间轴共同完成，下面介绍常用的预览与播放操作。

## 播放控制

- 菜单 **播放 (Playback)** 或时间轴控件可开始 / 暂停预览。
- **倒序播放**：从末帧向首帧播放，检查反向动画。
- 播放速度（帧率）由工程 `fps` 决定，可在工程设置中调整。

## 洋葱皮（Onion Skin）

- 菜单 **视图 → 洋葱皮** 开关；设置项在 **视图 → 洋葱皮设置**。
- 开启后，当前帧前后若干帧以半透明叠加显示，便于观察动作连贯与位移轨迹。
- 可分别设置向前 / 向后的显示帧数与透明度。

## 参考帧（Reference Frame）

- 菜单 **视图 → 参考帧** 可将任意一帧设为前景或背景参考。
- 参考帧用于对比当前帧与目标姿态，与洋葱皮互斥（开启其一会自动处理另一）。
- 设置项在 **视图 → 参考帧设置**；不需要时用「清除参考帧」。

## 画布视图操作

- **平移**：在画布空白处拖动可平移视图。
- **缩放视图**：用滚轮或在 **画布 → 视图缩放** 中选择放大 / 缩小 / 适应窗口 / 重置。
- **缩放图片 vs 缩放视图**：**画布 → 滚轮模式** 子菜单决定滚轮是缩放视图还是直接缩放图片。
- **背景**：**画布 → 背景** 可切换背景色或棋盘格，方便查看透明区域。

## 画布辅助显示

- **栅格化预览**：工具栏的 **栅格化预览** 开关（Rasterization Preview ON/OFF）可让预览逼近最终输出。开启后，只要视图放大超过 1.0 倍，画布即按最终输出的整数像素网格、以最近邻方式显示（关闭平滑插值），所见即导出所得。点击工具栏的 **栅格化设置** 打开对话框，可设定：
  - 是否启用栅格化预览；
  - 是否显示格线（割线）以及格线颜色；
  - **倍率阈值**：仅控制格线（割线）的显隐——只有当视图放大超过该倍率时才叠加像素网格线，避免在一般缩放下满屏都是线。注意栅格化渲染本身由上方开关 +「放大 > 1.0 倍」决定，不受倍率阈值影响。
  这些设置为全局保存，与具体工程无关。
- **画布边框**：**画布 → 画布边框设置** 中调整内侧 / 外侧边框的颜色与宽度，便于对齐。
- **锚点手柄**：当锚点模式为自定义时，画布上出现可拖拽的锚点，拖动即改轴心位置。
